# 科学コンテスト表彰式の作品紹介・約4分

対象は城東小学校3年・竹井奏太さんの研究「自分の足に合う3Dプリントのランニングシューズ」です。案内の「3 作品の紹介について」は項目番号として扱い、この1作品のきっかけ、研究内容、感想を紹介します。

約2分の元動画を通常の速さで流し、途中で3回止める構成です。読み上げは約870字。動画の再生中も話すため、元動画の音声はミュートにします。本文は短い文を中心にし、難しい漢字や道具の名前はひらがな・カタカナにしました。

## 大人向け・練習と当日のメモ

- 最初に一度、動画を止めながら声に出して通します。4分は設計上の目安で、本人の読み上げ時間は未計測です。3分50秒〜4分10秒くらいを練習の目標にします。
- 再生中の説明が早く終わったら、画面を見てもらう間にします。停止中は表の時刻だけで急に再開せず、本人がその段落を読み終えた合図で再開します。
- 4分を少し超えても、依頼の3〜5分の範囲です。時間に合わせて早口にさせるより、句点ではっきり区切ることを優先します。
- 時間が長いときは、最後の「しっぱいしても、作り直すと少しずつよくなることが分かりました。」を省けます。「一回ずつなので、くつのおかげかはまだ分からない」という説明は残します。
- 「うれしかったです」などの感想は、本人が読んで自分の気持ちに合うか確認し、いつもの言い方に変えてかまいません。
- 実物を舞台に持ち込める場合は、2回目の停止中に完成したくつを少し持ち上げると伝わります。実物なしでも、この台本だけで話せます。
- 会場で動画の再生と一時停止ができるか、事前に確認します。元動画には英語字幕があるため、音声をミュートにし、説明は本人の日本語で伝えます。
- 停止位置は実際の静止画で確認済みです。プレーヤーの操作によるずれがある場合は、秒数と操作表の画面の両方を目印にします。
