# A3縦スケッチブック・レイアウト

小学3年生のかなたくんの夏休みの自由研究を、A3縦（297 × 420 mm）のスケッチブック10ページにまとめるための台紙データです。各SVGは実寸のA3で作られており、黄色の枠が写真を貼る場所、青い枠が手書きで仕上げる場所です。

## 使い方

1. 各SVGをA3縦で、**拡大・縮小なし（100%）**で印刷します。
2. 写真の枠に、ファイル名どおりのL判プリントを貼ります。縦向きの枠は89 × 127 mm、横向きの枠は127 × 89 mmです。
3. 鉛筆や色ペンで、青い点線枠の質問・図・結果をかなたくん自身の言葉で書きます。

`images/report` と `images/3d-cad` のPNG/JPG画像28枚は、すべて一度ずつ配置しました。`images/report/report-front-page.pdf` は写真ファイルではないため、L判写真枠には含めていません。表紙の文字の参考として使えます。

| ページ | 内容 | 写真枚数 |
| --- | --- | ---: |
| 1 | 研究のきっかけ | 2 |
| 2 | 市販シューズの調査 | 3 |
| 3 | 会社ごとの工夫の比較 | 3 |
| 4 | 足の3Dスキャン | 3 |
| 5 | AIとCADでの設計 | 4 |
| 6 | 3Dプリントの失敗と調整 | 3 |
| 7 | アッパーの試作とフィット確認 | 3 |
| 8 | インソールとプレートの準備 | 3 |
| 9 | プレート入りソール | 4 |
| 10 | 結果・感想・次の改良 | 0 |

この順番なら、**なぜ作るのか → 調べる → 自分の足を測る → 設計する → 試す → 工夫する → 分かったこと**という自由研究の流れになります。
