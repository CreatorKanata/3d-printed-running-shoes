# 科学コンテスト 2026 提出用レイアウト

東京銀座ライオンズクラブ・早稲田大学科学コンテスト 2026の要項に合わせた、A3縦2枚のSVGです。

| ページ | 内容 |
| --- | --- |
| `k-dash-science-contest-page-1.svg` | 研究の動機、予想、調査、足の3Dスキャン、設計、試作と材料選び。 |
| `k-dash-science-contest-page-2.svg` | 重さと400m走の比較、走行中の観察、考察、次に調べること。 |

## 提出前の確認

- A3縦（297 mm × 420 mm）で、原寸・カラー印刷する。
- 先頭に研究テーマ、学校名、学年、氏名を記載済み。要項どおりクラス名は入れていない。
- 時間の結果は、400mをそれぞれ1回測った今回の比較である。靴だけの効果とは断定せず、次回は同じコース・条件で複数回測る計画を示している。
- 使用写真はSVGに埋め込んであるため、SVGファイルだけを別のパソコンに渡しても表示される。印刷前に、SVGをブラウザまたはInkscapeで開いて、画像が表示されることを確認する。
- 写真は自分たちで撮影したものとして使用する。外部の写真や図を追加する場合は、出典を追記する。

## 制作のねらい

色鉛筆・マーカー・手書き風の矢印や星を使いながら、見出しと測定値は太く読みやすくしました。独創性は「自分の足の3Dスキャンから靴を作ったこと」、分析力は「重さと400mの測定値、1回の測定だけでは結論にできないという考察」で伝える構成です。
